# 사용자 대화에서 추가된 요구와 변경

보관일: 2026-11-10. 이 파일은 이 프로젝트 대화의 사용자 지시를 발췌·정리한 것으로, 교수님 과제 공지나 회의록 원문이 아니다. 원문 자료는 이 디렉터리의 별도 파일에 보관한다.

## 처음 전달한 민세원 담당 항목

사용자가 전달한 항목은 다음과 같다. Notion 프로젝트 개요에도 같은 역할 항목이 있다.

> - 민세원
>   - 모델 학습 및 평가 담당
>   - 모델은 3개 정도 선정(baseline 및 특성 다른걸로, GNN 모델도 포함)
>   - 원본데이터로 모델 학습 및 평가
>   - 데이터 전처리 및 차종 추출 완료된거 포함
>   - 5-core를 원본으로

여기서 모델 실험의 기본 입력인 ‘원본’은 전달된 전처리 5-core를 가리킨다. 제안서 RQ1의 필터링 이전 raw/0-core 데이터 분석과 구분한다. 차종 특징을 이용한 조건 비교도 담당 범위에 포함되지만, 현재 전달받은 processed 폴더에는 해당 특징 테이블이 없어 수행하지 못했다.

## 이후 사용자 지시로 구체화한 내용

| 항목 | 사용자 지시와 실제 적용 |
|---|---|
| 작업 위치 | `~/git`의 별도 프로젝트. SecondBrain에 코드·가상환경·결과를 쓰지 않는다. |
| 모델 선택 | 특성이 다른 약 3개 모델의 선정을 위임했다. 최신 논문만을 의무적으로 재현하라는 요구는 아니다. |
| Popularity | ‘인기 순도 아예 베이스라인으로 하나’ 요청. 결정적 1회 기준선으로 추가했다. |
| 대조학습 | 강의계획서의 대조학습을 고려해 XSimGCL을 추가했다. 최종 구성은 BPR-MF·LightGCN·XSimGCL + Popularity다. |
| 실행 환경 | Mac 부하를 원하지 않아 기존 크레딧이 있는 Colab GPU 사용을 선택했다. 새 구독/GCP 유료 학습 VM을 구매하지 않았다. |
| 최적화·문서화 | GPU 구현을 검증하고 최적화 조건·주의점을 프로젝트 AGENTS.md와 GPU_REVIEW.md에 기록하도록 요청했다. |
| 본실험 | 빠진 평가·기록 기능을 보완한 뒤 seed 3개로 학습·평가하고 결과를 정리하도록 요청했다. seed는 42·43·44다. |
| 저장·진행률 | 세션 상실에도 결과가 남도록 Drive 자동 저장과 진행 로그를 요구했다. JSONL 이벤트, CSV 지표, progress.txt/JSON을 사용했다. |
| 자동 복구 | Mac/LLM이 계속 지켜보지 않도록 기존 Ubuntu 서버 제어기와 checkpoint 복구를 적용했다. |
| Git | git init 및 변경 commit을 요청했다. 원본 데이터·추천·checkpoint·credentials는 Git에 넣지 않는다. |
| 이번 인수인계 | 회의록·제안서 사본, 과제 설명, 세원 담당 범위를 프로젝트에 모아 다른 채팅에서도 이어갈 수 있게 정리하도록 요청했다. |

## 해석 범위

- 모델·운영 방식 변경은 사용자 후속 지시와 로컬 실행 계획이다. Notion 제안서 원문을 수정한 것이 아니다.
- 수업에서 XSimGCL 자체를 가르쳤다는 확인은 없다. 그래프 대조학습과 추천은 강의계획서상 관련 주제다.
- 이 파일은 출처 기록이다. 새로운 사용자 요청이 오면 그 요청과 적용되는 AGENTS.md를 따라 작업 범위를 정한다.
